2048 Game in C

The game uses 4*4 grid where players move and merge matching numbers to reach 2048 using the C 
programming language.


Features:
4*4 game board,
Arrow key for moving,
Automatic merging of matching numbers,
Random generation of new numbers,
Score tracking,
Winning and losing condition, and 
Option to exit the game using the E key

How to play:
Run the program,
Use arrow keys to move the numbers up, down, left and right,
When the boxes are with the same value, they merge into one,
Continue merging until you reach 2048!,
The game ends when there are no possible moves remaining , and 
Press E to exit the game


##How to run:
The game is written in C and currently uses conio.h for keyboard input, so it is intended to
run on Windows with a compatible C compiler.
Download or clone the repository,
Open the project in Visual Studio Code or another C development 
Compile the source code using GCC:
gcc main.c -o main.exe
Run the executable:
.\main.exe
